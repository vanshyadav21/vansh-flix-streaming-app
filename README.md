🎬 vans-flix — Cinematic Streaming Experience

📖 Overview
vans-flix is a modern, high-fidelity web streaming clone inspired by the signature aesthetic of Netflix, customized with exclusive vans-flix branding. 
Engineered with a mobile-first responsive layout, smooth micro-animations, glassmorphic navigation, 
interactive horizontal carousels, and an immersive video player simulation.

🌟 Key Features
 -🔴 Custom vans-flix Identity: Bold crimson branding, dynamic signature 'V' emblems, and tailored typography.

 -⚡ Cinematic Hero Billboard: Dynamic backdrop previews, rating tags, genre pills, audio spectrum frequency animations, and action triggers.

🎞️ Interactive Carousels:

 -Smooth horizontal scrolling with glassmorphic chevron paddles.

 -Hover expansion cards with synopsis peek, match percentage, and audio controls.

🔟 Top 10 in India Today: Oversized 3D hollow-stroke typographic numerals paired with high-impact movie banners.

🔍 Instant Live Search: Filter titles in real-time across the entire catalog without reloading the page.

📑 Detailed Modal Viewer:

  -Full backdrop synopsis & metadata (Audio format, 4K HDR, Rating).

  -Multi-episode selector and runtime tracker.

  -"More Like This" recommendation matrix.

▶️ Simulated Fullscreen Player: Custom video playback simulation with play/pause toggles, timeline scrub bar, volume controller, and cinematic blackout mode.

💾 My List (Watchlist): Add or remove titles on the fly with live toast confirmations and bookmark management.

🛠️ Tech Stack
  Markup & Architecture: Semantic HTML5 (Single-file architecture)

Styling: Tailwind CSS CDN with extended color palettes & custom keyframes

Icons: Lucide Icons

Typography: Inter & Bebas Neue via Google Fonts

State Management: Vanilla JavaScript (ES6+)

🚀 Quick Start / Local Setup
No build tools, bundlers, or heavy node_modules required!

1. Clone the repository:

git clone https://github.com/your-username/vans-flix.git
cd vans-flix
2. Run the application:

-Simply open the index.html file in any modern web browser:

-Direct Open: Double-click on index.html

-VS Code Live Server: Right-click index.html and click "Open with Live Server"

Terminal (Python):

-python3 -m http.server 3000

-Then navigate to http://localhost:3000 in your browser.
